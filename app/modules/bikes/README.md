# Bike garage (`bikes`)

Every bike's parts and how worn they are, from your rides: what is due, tyre pressures, batteries, spares and running cost.

Add yourself as a rider on the Bikes page, then your bikes. Rides come from Garmin Connect: save your Garmin Personal API key on the Bikes page (or import its activities CSV). Due parts go onto the Outdoors list when that is set up

How to use it: [docs/bikes.md](../../../docs/bikes.md).
